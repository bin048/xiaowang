# 桌面悬浮球开关补充说明

在「信息渡口 → 桌面资料入口」中使用「显示桌面悬浮球／隐藏桌面悬浮球」。球已显示但找不到时，点击「找回悬浮球」，移至鼠标所在屏幕的右侧中部并置顶，跨工作区可见。

开关控制独立 Electron 系统窗口；隐藏后程序继续待命，不丢弃投递。暂停接收时仍可使用开关。退出悬浮程序后，网页明确提示先启动本地联动组件；网页不能直接启动已退出的系统程序。

## 通信与确认

沿用 H5 配对令牌及可信来源校验。H5 调用 POST /api/desktop-control，仅接收 {"visible": true/false}，返回 202 与随机 command_id；此时只表示等待桌面执行。原生端心跳 /api/presence 上报真实 visible 与 applied，获取命令后执行显示／隐藏并回传命令 ID。H5 从 /api/status 确认相同 ID 和真实显示状态后才提示完成。无桌面心跳时拒绝命令；命令 15 秒过期，H5 12 秒未收到回执提示重试。控制不操作投递资料或人物数据。

拒绝无令牌、跨站、错误客户端角色及非布尔参数。错误响应关闭 HTTP 连接，避免未消费的拒绝请求正文污染后续请求。
