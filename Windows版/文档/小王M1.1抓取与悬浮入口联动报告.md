# 小王 M1.1 抓取与悬浮入口联动报告｜Windows 真机收尾

验收日期：2026-11-07 至 2026-11-08（北京时间）。本轮结论：在这台 Windows 11 真机上，虚构资料的桌面悬浮入口 → 本地服务 → H5 信息渡口 → 持久保存 → 真实 ACK 已跑通。达到本轮最小链路停止条件，暂停开发，等待审核。真实微信抓取尚未实现。

## 环境与证据范围

Windows 11 家庭中文版，系统 build 10.0.26200，x64；Python 3.14.6，Node.js 24.16.0，npm 11.13.0，Electron 45.2.3；浏览器使用本机 Edge。经 RustDesk 操作实际 Windows 桌面和终端，未使用 macOS 截图替代。TXT、DOCX、PDF 的实体鼠标拖入由用户在 Windows 端执行，代理随后从实际 SQLite 队列、入口 outbox 和 H5 ACK 核对。独立 API 操作测试与实体拖拽分开记录。

所有资料均为虚构，使用新建隔离目录与浏览器测试资料目录；未读取、迁移正式人物库或聊天。Windows 10、其他硬件/缩放/系统版本未单独验证。自动化浏览器测试使用实际 Edge 的隔离资料目录，部分为无头模式；桌面截图则来自可见 Windows GUI。

## 本轮代码修复

1. SQLite connect 改为 contextmanager，保留提交/回滚语义，在 finally 显式关闭连接，含初始化异常路径。未改事件 ID、ACK、SQLite 表及 H5 存储契约。
2. 真机发现原 SO_REUSEADDR 行为允许 Windows 第二次监听同端口，可能覆盖配对。新增 Windows SO_EXCLUSIVEADDRUSE，禁止端口复用；Unix 保持原复用行为。修复前失败与修复后 8/8 通过日志均保留。

Diff 在文档目录。H5、本轮 UI、六导航、人物、画像、事项、模型配置均未修改。单 HTML SHA256：`034d122c5d8bf3ca79376a62d7c15c80d1b8da0ef3e5db647af3224c94e19cda`。服务与 Electron 仍为可选独立组件，不创建第二套业务库。

## 迁移与回退

file 与 HTTP 不共享浏览器 origin，必须使用既有“完整备份”导出/恢复按钮。先在原 M1.0 单 HTML 导出 JSON，再在 HTTP 单 HTML 恢复，核对数量和人物 ID/事项关联/来源。新版新增虚构资料后再导出，回到独立旧版 file 恢复并重开验证。旧版原资料未被删除，损坏备份被拒绝且现有库不变。

Windows 测试数据：11 位虚构人物、46 份语料、2 个来源、1 个事项；新版新增后回退为 3 个来源、2 个事项。核心字段逐字段一致。实际备份、数量校验、截图在 Windows真机证据/迁移测试。备份不含模型 API Key、原文件二进制或桌面待投递队列。更早原 B 双单库备份格式转换未实现；不得将其当作本轮完整备份迁移已通过。

## 异常记录与限制

原端口独占测试真实失败后修复并复测；Electron 官方下载首次超时，后按官方支持的镜像机制安装并校验官方 SHA256，未关闭证书或安全校验。Windows x64 归档校验值：489cd061908e697394b004298bf5ffd345c935d10e8ca197ba819f019ab2dec0。安装依赖仍需要网络，本包不含 node_modules 或 Windows 二进制，首次按启动说明准备。

原生 API 联调首轮断言未等待异步 ACK，恢复测试前两轮的测试脚本存在窗口等待时序问题；修正测试等待方式后全部通过，未修改生产队列逻辑。失败日志保留，不计作通过。

远程模拟鼠标拖放未产生文件事件，不能据此声称实体拖放成功；最终使用用户 Windows 实体鼠标操作，并匹配独立新事件与 ACK。文件选择器另有独立验证。Windows 在服务关闭后另执行既有 H5 回归 16 项全部通过，使用实际 Edge 无头隔离浏览器，包含手动录入、Word 导入、六导航与备份恢复；未逐项人工重测全部 AI 或模型调用功能。
