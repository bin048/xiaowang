# 一键启动与独立关闭

## Windows首次准备

1. 将完整交付包解压到普通本地目录，保留三个组件的相对位置。不要覆盖M1.0或原B文件。
2. 准备Python 3.10以上、Node.js 22.12以上、npm。它们是运行前提；本包不自动安装系统软件，不注册系统服务，不设开机自启。
3. 首次双击 `安装悬浮依赖.cmd`。它在Electron悬浮入口目录执行npm ci及Electron下载，锁定45.2.3。下载需要网络；失败会提示，不假装入口可用。不要在未解压的ZIP内运行。
4. 双击 `一键启动.cmd`。启动本机服务、打开已配对H5、启动真实Electron悬浮窗口。Windows 11 真机已用虚构资料验收；其他 Windows 版本仍需兼容验证。

依赖依据：[Electron 45.2.3官方发布页](https://releases.electronjs.org/release/v45.2.3)。拖入文件采用官方 [webUtils.getPathForFile](https://www.electronjs.org/docs/latest/api/web-utils)，未向网页暴露任意fs或HTTP接口。当前锁文件的npm ci已在隔离work目录验证。交付源码和锁文件，不含平台二进制或node_modules。

## 日常操作

- 单击/右击悬浮球打开原生菜单。选择“投递一段文本”，粘贴你主动提供的内容后保存投递；也可拖入选中的文本。
- 菜单“选择文件投递”，或把实际本机文件拖到球上。支持DOCX/PDF/PPTX/TXT/MD/CSV，单文件15MB，一次拖入最多5个。
- 球显示“已交接，等待小王收件”时，表示资料在服务队列，还没有H5回执。打开小王并保持接收，才会显示“小王已收到并保存”。部分提取/提取失败会明确标注。
- 需要演示抓取，用菜单“获取虚构消息示例”，或H5“接收虚构消息”。这里只产生虚构资料，没有微信读取功能。
- H5右上原设置与六导航保持原样。连接入口位于信息渡口，详细来源/事件/时间/回执按需展开。已收到的资料可在资料记录中打开；不会强制建人物或正式事项。
- H5关闭后，资料仍留在入口outbox和服务队列。重新打开小王，接收后补发回执。服务离线时入口继续先保存主动提供的文本/文件，恢复后点击重试即可。
- “暂停接收”只暂停H5取件，保留队列；“连接并接收”恢复。服务重启轮换配对码后，须从球菜单重新打开小王。

## 独立关闭

- 悬浮菜单“隐藏悬浮球”只隐藏窗口，仍可投递重试，托盘点击可唤回。
- “退出悬浮入口”结束Electron及其计时器/窗口；**独立服务仍可运行**，这是有意保留的组件，不是异常残留。H5仍可收服务已有队列。
- `仅关闭本地服务.cmd` 只停止Python服务。球会提示不可用，待处理资料不删除。已打开的H5仍可手动录入/上传并保存。
- `关闭全部.cmd` 请求退出当前运行目录的悬浮入口，同时用专用管理凭证停止本地服务，不按进程名批量杀其他Python/Electron。
- 服务自己的终端也可按Ctrl+C关闭。强制关机后重启仍以相同事件ID重试。
- H5“撤销本机配对”使普通访问立即失效，队列保留。重启一键启动才重新配对；管理停止接口仍能工作。

## 数据在哪里

Windows默认 `%LOCALAPPDATA%\小王M1.1运行数据`：

- `入口待投递.json`：未收到回执前的事件、文本和文件字节；收到回执后保留元数据，清除本地文件base64副本。
- `投递队列.sqlite3`及WAL：服务事件、文件原件和H5回执，不包含人物或事项数据库。
- `本机配对.json`：当前启动的角色凭证，仅在本机使用，不要随报告转发。
- `Electron窗口数据`、`悬浮位置.json`：窗口和Electron自身缓存。

H5人物和渡口数据仍保存在当前浏览器、当前origin的本地存储。服务、入口和浏览器是三个不同的持久边界，请不要把服务队列当作完整人物备份。真实资料试用前先按M1.0方式做完整备份。

直接双击单HTML（file://）仍可独立手动使用，但与HTTP页面的浏览器存储可能不互通。联动时固定使用球打开的 `http://127.0.0.1:8915/小王.html`，不要随意换端口/浏览器。服务停止后，已经打开的H5可继续手动操作；若要重新加载HTTP页面，需先启动服务。磁盘上的单HTML独立保留。

## 命令行与排障

```text
python 启动联动.py
python 启动联动.py --service-only
python 启动联动.py --stop-service
python 启动联动.py --stop
```

高级：`--data-dir`可指定隔离运行目录，`--port`可指定空闲端口。Electron读取环境变量 `XW_DATA_DIR`；自定义Node路径用 `XW_NODE`。参数只能由本机用户启动设置，网页不接受路径或任意抓取命令。

端口占用会明确失败，不覆盖已有配对；损坏outbox会拒绝加载并保留原文。先备份运行目录后人工检查，不要删库“修复”。若依赖没下载，H5/服务可以先使用，悬浮入口不能算已启动。日志不要包含正文或配对码。


悬浮球找不到时：在小王「信息渡口」顶部点击「显示桌面悬浮球」或「找回悬浮球」，会移至当前屏幕右侧。点击「隐藏桌面悬浮球」只隐藏窗口；退出后需重新启动本地联动组件。
