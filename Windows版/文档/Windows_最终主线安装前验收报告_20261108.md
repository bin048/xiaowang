## 四、数据与边界

- 三个持久边界互不等价：**服务队列**（SQLite + WAL）、**入口待投递**（outbox JSON）、**H5 业务数据**（浏览器 IndexedDB）。服务队列不是人物/事项备份。
- 固定 origin 为 `http://127.0.0.1:8915/小王.html`；H5 页面与配对码不得分离传播。
- 服务每次启动会**轮换配对码**，H5 需按悬浮入口方式重新打开（本次 S11 已验证）。
- 端口独占：Windows 下使用 `SO_EXCLUSIVEADDRUSE`，端口被占用时明确失败，不覆盖已有配对。
- 开机自启项只启动本地投递服务，不含悬浮球与浏览器；要看球请用桌面快捷方式。

## 八、安装后发现并修复的问题（2026-11-08 当天）

### 8.1 双击桌面快捷方式无反应（已修复）

- **现象**：双击 `桌面\小王 M1.1.lnk`，控制台窗口一闪即退；重定向日志显示
  `'nul' is not recognized as an internal or external command` 与 `'0' is not recognized ...`。
- **根因**：交接包内的 `.cmd` 是 **LF（`0A`）换行**，由 macOS 侧生成。cmd.exe 按 CRLF 逐行解析，
  `chcp 65001 >nul` 被拆成 `chcp 65001 >` 与 `nul`，后续 `if %errorlevel%==0 (...)` 同样被拆坏，
  脚本从未真正执行到 `启动联动.py`。
- **修复**：把安装目录与 staging 内全部 `.cmd`（共 16 个文件：`一键启动.cmd`、`仅关闭本地服务.cmd`、
  `关闭全部.cmd`、`安装悬浮依赖.cmd` × 4 份副本）统一转换为 CRLF，保持 UTF-8 无 BOM，脚本内容与逻辑未改。
- **复测**：直接双击桌面快捷方式 → 本地服务（8915）、悬浮球「小王系统悬浮入口」、浏览器 H5 三者全部拉起；
  执行 `关闭全部.cmd` 后 electron / python / node 全部退出，8915 端口释放。
- **遗留**：`Documents` 下的交接包原件仍为 LF（保持只读、不破坏其校验清单）。今后若再从该包复制到 Windows，
  必须先做一次 CRLF 转换，否则所有 `.cmd` 都会失效。
