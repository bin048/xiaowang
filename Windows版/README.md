# 小王 XiaoWang AI · Windows 版

这是同一套产品的 **Windows 11 真机版本**：桌面悬浮球（Electron）+ 本地服务（Python）+ 单文件工作台（H5），
与仓库根目录的 macOS 版功能同源，启动器与路径适配为 Windows。

> 与 macOS 版的差别只在「怎么启动」和「数据放哪」，业务逻辑、存储契约、服务接口一致。
> 本目录是 2026-11-08 12:18 的 Windows 交付快照；根目录是持续更新的 macOS 主线（额外含人物预设面板、
> Obsidian 知识库导出等）。两边的 `源码/` 请勿交叉替换。

## 快速开始（Windows 11）

前置：**Python 3.10+**、**Node.js 22.12+**（首次准备依赖需要联网）。

```
1. 安装悬浮依赖.cmd     # 等价于 npm ci + 下载 Electron 运行时（只需一次）
2. 一键启动.cmd         # 起本地服务 → 拉起悬浮球 → 打开工作台
```

退出：

| 脚本 | 作用 |
| --- | --- |
| 重开悬浮球.cmd | 只重启悬浮球入口，本地服务与队列保留 |
| 仅关闭本地服务.cmd | 只停本地服务，悬浮球仍在 |
| 关闭全部.cmd | 关闭这套组件（待投递记录保留） |

- 工作台是单文件 `小王M1.1_桌面联动.html`，服务地址固定 `http://127.0.0.1:8915`。
- 运行数据默认在 `%LOCALAPPDATA%\小王M1.1运行数据`（配对凭据、SQLite 队列、日志）。可用 `--data-dir` 改。
- 本仓库**不含** `node_modules` 与 Electron 二进制（体积原因，且应由 `安装悬浮依赖.cmd` 按本机平台下载）。

## 已验证范围（Windows 11 真机）

- 悬浮球拖入文件 → 归属固化 → 本地服务排队 → 工作台接收 → ACK，全链路用**虚构资料**跑通；
- 服务独占端口、连接显式释放、离线恢复与迁移回退均有记录；
- 证据与结论见 `文档/Windows基础链路收尾报告.md`、`开始阅读.md`。

## 边界（如实说明）

- **不含真实微信抓取**：仓库不附带任何聊天抓取模块与真实聊天记录；投递入口只接受用户主动拖入/粘贴的资料。
- **不含系统级安装**：不写注册表自启、不装服务，全部为用户态进程，关掉即退出。
- 模型功能需在「设置」里填自己的 OpenAI 兼容 Key，密钥仅存本机。
