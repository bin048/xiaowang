# 测试复现环境

核心运行：Python 3.9+、Node.js 22.12+、package-lock锁定的Electron 45.2.3。运行Windows自动检查.cmd不需要Playwright，不会替代系统桌面操作。

可选：重新运行隔离浏览器迁移自动测试（无需正式浏览器资料）。本轮macOS使用Playwright 1.62.1自带Chromium。Windows命令提示符中进入本目录后执行：

```bat
npm install --no-save playwright@1.62.1
npx playwright install chromium
set "NODE_PATH=%CD%\node_modules"
set "XW_PYTHON=python"
node "..\测试\browser-migration.cjs"
```

XW_PYTHON需指向可直接执行的Python可执行文件。若系统只有py启动器，先用 `py -3 -c "import sys; print(sys.executable)"` 得到Python路径再设置。不要把“py -3”作为一个可执行文件名填入。

迁移测试使用OS临时目录，全新浏览器资料，不读取正式浏览器数据，服务端口18921；测试结束关闭自己启动的浏览器与服务并移除临时目录，只保留测试证据。结果有platform标记；在Windows重跑才会有windowsTested:true。它依然不能证明物理拖拽、托盘或Windows关闭全部行为。

若要跑真实Electron自动测试，另将XW_TEST_ELECTRON设置为本包Electron悬浮入口/node_modules/electron/dist/electron.exe，再执行测试/electron-e2e.cjs。该脚本以程序API移动/选文件，不能当成Windows系统鼠标拖入证据。本轮人工验收必须执行W01–W15。
