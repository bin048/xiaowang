# 小王 M1.1 Windows 真机验收交付

Windows 11 真机基础链路已用虚构资料跑通；真实微信抓取尚未实现。已按本轮停止条件暂停开发。

请先读 文档/Windows基础链路收尾报告.md。Windows真机证据 包含真实桌面截图、SQLite资源日志、ACK、离线恢复、迁移回退与失败复测记录。历史macOS验证 仅作历史证据，不计作Windows通过。

首次使用：完整解压 → 准备 Python 3.10+、Node.js 22.12+ → 安装悬浮依赖.cmd → 一键启动.cmd。依赖需网络下载；包内不含node_modules或Electron二进制。

退出球仅结束入口，服务独立保留；仅关闭本地服务.cmd 停服务；关闭全部.cmd 关闭这套组件。H5仍是 小王M1.1_桌面联动.html 单文件，file与HTTP的资料迁移按报告做完整备份。

本轮只修改服务的连接显式释放及Windows端口独占；H5和业务存储契约保持不变。详细启动与数据位置见 文档/一键启动与独立关闭说明.md。
